# clock

A modern world clock app built with React + Vite.

## Run locally

1. Install dependencies:
   npm install
2. Start the dev server:
   npm run dev
3. Build for production:
   npm run build

## Deploy to GitHub Pages

The repo includes a GitHub Actions workflow in `.github/workflows/deploy.yml` that builds the app and deploys it to GitHub Pages automatically on pushes to `main`.

## Features

- Search and add cities and timezones
- Add your local timezone instantly
- Live analog + digital clock display
- Remove individual clocks or clear all
- Persists selected timezones in browser storage
